## 3. Materi Pembelajaran

Berdasarkan Course Summary dalam dokumentasi pelatihan, materi yang dipelajari meliputi:

### A. Data Visualization Introduction

Visualisasi data merupakan representasi grafis dari informasi dan data. Dengan menggunakan elemen visual seperti chart, grafik, dan maps, visualisasi data membantu melihat dan memahami tren, outlier, serta pola dalam data.

### B. Jenis-Jenis Data Visualization

Jenis visualisasi data yang dipelajari meliputi:

- **Bar & Column Chart:** Membandingkan data berdasarkan kategori.
- **Line Chart:** Menampilkan perubahan atau tren data.
- **Donut Chart:** Menunjukkan proporsi atau persentase.
- **Combo Axis Chart:** Menggabungkan dua bentuk visualisasi dalam satu grafik.

### C. Contoh Penerapan

- Bar Chart untuk membandingkan jumlah penjualan antarproduk.
- Line Chart untuk melihat perubahan penjualan setiap bulan.
- Donut Chart untuk menampilkan persentase pangsa pasar.
- Combo Axis Chart untuk membandingkan data penjualan dengan target secara bersamaan.

## 4. Mini Task – Data Visualization Using Excel

Pada tahap praktik, dilakukan pembuatan visualisasi data menggunakan Microsoft Excel berdasarkan dataset produksi daging di Indonesia.

Hasil pengerjaan menghasilkan enam visualisasi sebagai berikut:

| No. | Visualisasi | Tujuan |
|---|---|---|
| 1 | Perbandingan Produksi Daging Sapi per Provinsi Tahun 2022 | Membandingkan produksi antarprovinsi |
| 2 | Total Produksi Daging Ayam di Papua | Menampilkan proporsi produksi Papua dan Papua Barat |
| 3 | Total Produksi Daging Berdasarkan Produk | Membandingkan produksi berdasarkan jenis daging |
| 4 | Perbandingan Banyak Pakan dan Total Pengeluaran Pakan Ternak Tahun 2020–2022 | Membandingkan jumlah pakan dan pengeluaran |
| 5 | Produksi Daging Sapi per Provinsi Tahun 2020–2022 | Membandingkan perkembangan produksi antarprovinsi |
| 6 | Total Produksi Daging Sapi per Tahun | Menampilkan tren produksi dari tahun 2020 hingga 2022 |
